# ADR-001

Title

Choose OpenAI GPT Model for Modernization Advisor

Status

Accepted

Context

Enterprise architects spend considerable effort assessing applications for modernization.

Decision

Use OpenAI GPT models to generate initial modernization recommendations.

Consequences

Positive

- Faster assessments
- Consistent recommendations
- Reusable prompts

Negative

- Responses require SME validation
- LLM may hallucinate
- Requires prompt engineering
